## 我们在解决什么

制造业数智化真正难的不是买软件，是三件没人愿意碰的事：

**一、数据对不上。**
MES 说做了 1000 件，WMS 说收了 980 件，ERP 说入了 990 件。三个系统三个真相，月度会对不上账，最后靠财务手工调平。这不是系统问题，是**契约问题**——系统之间没有一份双方都认的数据定义。

**二、现场不愿用。**
上线三个月，操作工绕过去用纸质单据。原因往往不是界面难用，而是**系统要求的操作顺序和真实工序不一致**。设计系统的人没在产线上站过一天。

**三、换不掉也改不动。**
十年前上的系统，厂商还在，源码没了；想加一个字段，报价六位数、排期三个月。**遗留系统不是技术债，是经营权问题。**

我们的方法：**用契约表锁住数据语义，用防腐层隔离遗留系统，用绞杀者模式逐步替换，让旧系统在被替换完之前一直能跑。**

## 代表作品

### QRCheck · 二维码标签校验工具集

给打印车间做的扫码校验工具。解决的问题很土：**几百张标签印出来，不知道有没有重码；几十种料号各有各的编码规则，靠人眼看不住。**

- 扫码枪接入（HID 键盘 / 串口双模式），重复即刻声光报警
- 按料号建规则，11 类校验条件（前缀/长度/段位/日期/字符集/正则等）
- 5 档处置动作：放行 / 提醒 / 拦截 / 锁码（密码解锁）/ 锁屏
- 纯本地运行，无需 Python 环境，单个 exe 双击即用
- 自带 114 项自检，打包后仍可自检

> 设计取舍写在仓库 README 里，包括我们明确承认挡不住的场景。

## 我们信什么

**一、器要合手。**
再先进的系统，操作工不愿意用就是零。所以我们先看工序，再画界面。

**二、承认边界。**
做不到的事当场说。锁屏挡不住 Ctrl+Alt+Del，我们就写在文档里，而不是等客户发现。

**三、让客户少等。**
衡量标准不是"我们技术多强"，是"客户的问题多久解决"。一个 20 分钟能修好的问题，不值得开三次会。

**四、长期伴随。**
不追求一次性交付的大单，追求客户下一套系统还找我们。
